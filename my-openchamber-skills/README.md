# OpenChambers AI Agent Skills Collection

A collection of custom **Skills** designed for OpenChambers and AI agent platforms.

## 📦 Skills Overview

| Skill Name | Purpose | Key Focus |
| :--- | :--- | :--- |
| **`interview`** | Interactive, step-by-step requirements gathering | Asks one question at a time to clarify user needs without overwhelming them. |
| **`doubt-drive-dev`** | Skeptical architectural and technical auditing | Challenges implicit assumptions, stress-tests edge cases, and enforces defensive design. |
| **`hostile-review`** | Uncompromising "Red Team" code & doc review | Delivers direct, evidence-based critique focusing on security, performance, and maintainability. |
